# Εργαστήριο ΑΕΠΠ

Εφαρμογή React και TypeScript με Vite, Tailwind CSS v4, TanStack Query, Axios, Lucide, clsx και tailwind-merge. Οι εκφωνήσεις, οι οδηγίες, οι λύσεις και η διεπαφή είναι στα Ελληνικά.

## Εκκίνηση

Από τον φάκελο aepp-generator-client:

```powershell
npm install
npm run dev
```

Ανοίξτε τη διεύθυνση που εμφανίζει το τερματικό. Για μεταγλώττιση: `npm run build`. Για προεπισκόπηση της έκδοσης παραγωγής: `npm run preview`.

## Ενδεικτικό διαγώνισμα

- Θέμα Α: Σωστό/Λάθος, πολλαπλή επιλογή, αντιστοίχιση και σύντομη απάντηση.
- Θέμα Β: Β1 συμπλήρωση πέντε κενών· Β2 πίνακας τιμών, έξοδος προγράμματος και μετατροπή ΓΙΑ σε ΟΣΟ.
- Θέμα Γ: δισδιάστατος πίνακας 12 × 7, έλεγχος εισόδου, σύνολα, μέσοι όροι και όλες οι ισοβαθμίες στο μέγιστο.
- Θέμα Δ: παράλληλοι πίνακες 20 μαθητών, συνάρτηση μέσου όρου και διαδικασία με παράμετρο εξόδου.

Κάθε θέμα έχει 25 μονάδες. Το πλήρες διαγώνισμα έχει 100 μονάδες και 8 ερωτήματα, με επιμέρους ζητούμενα και αναλυτική κατανομή μονάδων. Οι ολοκληρωμένες λύσεις περιλαμβάνουν δηλώσεις μεταβλητών και κώδικα ΓΛΩΣΣΑΣ. Η Α4 δίνει ρητά τμήμα προγράμματος με προϋποθέσεις δηλώσεων και αρχικοποίησης.

Η επιλογή «Εμφάνιση λύσεων» εμφανίζει και τις τιμές του πίνακα Β2. Η εκτύπωση ακολουθεί αυτή την επιλογή. Η «Λήψη» αποθηκεύει αρχείο JSON που περιέχει και τις λύσεις, ανεξάρτητα από την ορατότητά τους.

Οι ασκήσεις είναι σταθερό δείγμα: η ύλη και η δυσκολία αλλάζουν μόνο τα μεταδεδομένα. Η επιλογή θεμάτων φιλτράρει την προεπισκόπηση χωρίς αναπροσαρμογή μονάδων.

## Φάκελοι

- `src/api`: σύνδεση Axios, λειτουργίες React Query και ενδεικτικό διαγώνισμα.
- `src/components/common`: κουμπί, κάρτα και πεδίο εισαγωγής.
- `src/components/exam`: εμφάνιση θεμάτων, πίνακα τιμών, Markdown και κώδικα.
- `src/types`: τύποι συμβατοί με τις οντότητες και τα δεδομένα του .NET.
- `src/lib`: βοηθητικές συναρτήσεις και ελληνικές ετικέτες απαριθμήσεων.

## Μελλοντική παραγωγή θεμάτων

Το .NET διαθέτει ακόμη μόνο σημείο ελέγχου λειτουργίας. Η προδιαγραφή παραγωγής αποθηκεύεται στο γειτονικό έργο, στο αρχείο `AeppGenerator/src/AeppGenerator.Infrastructure/Prompts/ExamGeneration.el.md`. Δεν έχει ακόμη συνδεθεί με μοντέλο παραγωγής θεμάτων.

Για μελλοντική σύνδεση, αντιγράψτε το `.env.example` σε `.env.local`, ορίστε `VITE_USE_DEMO=false` και επανεκκινήστε το Vite. Χρειάζεται υλοποίηση του `POST /api/exams/generate` που επιστρέφει `ExamDto`. Η προετοιμασμένη συνάρτηση `useExam(id)` αναμένει `GET /api/exams/{id}`.

Το αίτημα περιέχει `title`, `academicYear`, `targetTopic`, `difficulty`, όπως η τρέχουσα εντολή του .NET. Οι επιλεγμένες ενότητες ύλης ενώνονται στο `targetTopic`. Η επιλογή θεμάτων φιλτράρει μόνο την απόκριση, επειδή η εντολή του διακομιστή δεν περιλαμβάνει ακόμη αντίστοιχο πεδίο.

Το Vite προωθεί το `/api` στο `http://localhost:5210`. Η διεύθυνση αλλάζει με το `API_PROXY_TARGET`. Για παραγωγή χρειάζεται αντίστοιχη προώθηση αιτημάτων ή ρύθμιση `VITE_API_BASE_URL` και CORS. Τα κλειδιά υπηρεσιών μοντέλων ανήκουν αποκλειστικά στον διακομιστή, όχι σε μεταβλητές `VITE_`.

Τα τεχνικά ονόματα ιδιοτήτων και οι τιμές `Easy/Medium/Hard`, `ThemeA/ThemeB/ThemeC/ThemeD` διατηρούνται για συμβατότητα. Οι εμφανιζόμενες ετικέτες είναι ελληνικές. Το `executionTraceJson` περιέχει `columns` και `rows`: η πρώτη στήλη είναι ο αριθμός επανάληψης, οι υπόλοιπες εμφανίζονται με τις λύσεις.

## Έλεγχοι και όρια

Η μεταγλώττιση TypeScript/Vite ολοκληρώνεται επιτυχώς. Ελέγχθηκαν τα αθροίσματα μονάδων, οι σχέσεις αναγνωριστικών, η επιλογή θεμάτων και οι τιμές του Β2 με ανεξάρτητο αριθμητικό υπολογισμό. Έγινε έλεγχος ελληνικής εμφάνισης και λύσεων στον περιηγητή.

Δεν έχει πραγματοποιηθεί εκτέλεση των προγραμμάτων στον επίσημο Διερμηνευτή της ΓΛΩΣΣΑΣ. Ο επεξεργαστής κώδικα της εφαρμογής είναι απλό πεδίο κειμένου και δεν εκτελεί ή πιστοποιεί προγράμματα.

Αναφορά σύνταξης: [Σχολικό βιβλίο — Βασικά στοιχεία προγραμματισμού](https://www.ebooks.edu.gr/ebooks/v/html/8547/2718/Pliroforiki_G-Lykeiou_html-empl/index7_1.html).

# Συγχρονισμός θέματος και αντίθεση

Ο editor είναι προσαρμοσμένος editor ΓΛΩΣΣΑΣ (textarea με συντακτικό overlay), όχι Monaco. Το `resolveEditorTheme` εφαρμόζει πάντα τη λευκή παλέτα στο light mode και διατηρεί την προτιμώμενη σκοτεινή παλέτα για το dark mode.

Το `applyTheme` είναι η κοινή εφαρμογή των `data-theme`, `.dark`, `color-scheme`, πυκνότητας και μεγέθους γραμματοσειράς στο `<html>`. Καλείται πριν από το πρώτο React render και από το `SettingsContext` σε κάθε σχετική αλλαγή. Το υπάρχον storage listener συγχρονίζει τις αποθηκευμένες αλλαγές μεταξύ καρτελών.

Τα `editor-theme.css` και `theme-surfaces.css` καλύπτουν editor, αρίθμηση, caret, syntax overlay, οδηγό εντολών, φυσικά dialogs και ξενάγηση. Τα scoped χρώματα του textarea παραμένουν διαφανή όταν εμφανίζεται το syntax overlay και γίνονται ορατά κατά την πληκτρολόγηση.

## Επαλήθευση στις 14/10/2026

- `npm run test:settings`: 10 επιτυχείς έλεγχοι, περιλαμβανομένων root toggle/reset και διατήρησης προτίμησης σκοτεινής παλέτας.
- `npm run build`: επιτυχές TypeScript/Vite build. Παραμένει προειδοποίηση μεγέθους του βασικού bundle.
- Chromium μέσω Playwright: desktop 1440 × 1000 και viewport κινητού 390 × 844. Δεν πρόκειται για δοκιμή σε φυσικό κινητό.
- Light: υπολογισμένο background σε body, editor shell και gutter `rgb(255, 255, 255)`· βασικό κείμενο `#0f172a`, αρίθμηση `#475569`.
- Dark Default: editor `#0f172a`. VS-Code Dark: editor `#1e1e1e`. Φόντο εφαρμογής `#0b1220`, dialogs/οδηγίες `#151f30`, βασικό κείμενο `#e2e8f0`.
- Πραγματική εναλλαγή από τον διακόπτη ρυθμίσεων, επαναφορά light με αποθηκευμένη σκοτεινή παλέτα και reload σε dark.
- Ελέγχθηκαν οπτικά ο editor, οι ρυθμίσεις και ο οδηγός εντολών. Η ξενάγηση μετρήθηκε με υπολογισμένα CSS χρώματα: τα ενεργά κείμενα και κουμπιά του πρώτου βήματος είχαν αντίθεση τουλάχιστον 6,68:1.
- Ο οδηγός εντολών στο μικρό viewport είχε σκούρο φόντο/ανοιχτό κείμενο και δεν προκάλεσε οριζόντια υπερχείλιση της σελίδας.
- Το παράθυρο ρυθμίσεων κεντράρεται με `margin: auto`.

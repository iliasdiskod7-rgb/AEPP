# Προσωπικές σημειώσεις κώδικα

Στον διερμηνευτή, «💾 Αποθήκευση στις Σημειώσεις» ανοίγει modal τίτλου και προσωπικού σχολίου. Προτείνεται όνομα από την εντολή ΠΡΟΓΡΑΜΜΑ. Αποθηκεύεται το κείμενο αυτούσιο, ακόμη και αν δεν ολοκληρώνεται η σύνταξη. Η αυτόματη τοπική αποθήκευση πρόχειρου παραμένει ανεξάρτητη από τη μόνιμη βιβλιοθήκη.

Η Αρχική εμφανίζει τις τέσσερις πιο πρόσφατες σημειώσεις. Η «Προβολή όλων» και η επιλογή «Οι Σημειώσεις μου» ανοίγουν τη βιβλιοθήκη με αναζήτηση τίτλου/σχολίου. Η «Προβολή» δείχνει όλον τον κώδικα. Από εκεί αλλάζουν τίτλος/σχόλιο ή ανοίγει η άσκηση στον διερμηνευτή. Η ενημέρωση από τον editor κρατά την ταυτότητα της σημείωσης· η επιλογή «Αποθήκευση ως νέα σημείωση» δημιουργεί αντίγραφο.

Αποθήκευση: SQLite `CodeNotes` στο υπάρχον accounts.sqlite, με migration `202610120001_AddCodeNotes` του AssessmentDbContext. Το migration εκτελείται από τον υπάρχοντα μηχανισμό εκκίνησης API, χωρίς αλλαγή των αποθηκευμένων λογαριασμών/διαγωνισμάτων. Χρειάζεται επανεκκίνηση της νέας έκδοσης backend για εφαρμογή του migration.

API: `GET/POST /api/notes`, `GET/PUT/DELETE /api/notes/{id}`. Όλες οι ενέργειες απαιτούν σύνδεση και φιλτράρονται με το sub του JWT. Το UserId δεν λαμβάνεται από το σώμα. Ξένη σημείωση επιστρέφει 404 σε ανάγνωση, ενημέρωση και διαγραφή. Ο έλεγχος εφαρμόζεται στο SQL query, όχι μόνο στη διεπαφή.

Όρια: τίτλος 200 χαρακτήρες, κώδικας 100.000, σχόλιο 5.000, payload 700.000 bytes. Το προαιρετικό `expectedUpdatedAt` του PUT και το EF concurrency token αποτρέπουν αντικατάσταση νεότερης έκδοσης· σύγκρουση επιστρέφει 409. Οι ημερομηνίες αποθηκεύονται UTC. Ο κώδικας δεν αναλύεται/εκτελείται από τα endpoints σημειώσεων.

Ο NotesProvider ανανεώνει άμεσα τη λίστα μετά από αποθήκευση/διαγραφή και απομονώνει αποτελέσματα ανά λογαριασμό. Οι απαντήσεις επαληθεύονται με Zod. Ο editor αναδημιουργείται στην αλλαγή λογαριασμού και τα πρόχειρα κώδικα χρησιμοποιούν διαφορετικό κλειδί LocalStorage ανά χρήστη. Οι σημειώσεις απαιτούν διαθέσιμο API για μόνιμη αποθήκευση· αποτυχία αποθήκευσης παραμένει ορατή στο modal.

Το Εργαστήριο Βρόχων αφαιρέθηκε από το κεντρικό μενού. Είναι διαθέσιμο αποκλειστικά από το Μάθημα 13, ως προαιρετική δραστηριότητα εμβάθυνσης με lazy loading.

Έλεγχοι: `npm run test:notes`, `npm run build`, `npm run test:notes:integration` μετά από backend build Release. Για απομονωμένο build ορίζεται `AEPP_NOTES_API_DLL` στην πλήρη διαδρομή του Api.dll. Το integration test δημιουργεί προσωρινή βάση και ελέγχει δύο διαφορετικούς χρήστες, CRUD, αυτούσια CRLF/σχόλια, σύγκρουση έκδοσης και διατήρηση μετά από επανεκκίνηση.

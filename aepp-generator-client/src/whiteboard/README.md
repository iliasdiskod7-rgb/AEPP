# Ψηφιακός Πίνακας ΑΕΠΠ

Η καρτέλα «Πίνακας & Διαγράμματα» υλοποιείται με React και SVG, χωρίς εξωτερική βιβλιοθήκη σχεδίασης.

- `model.ts`: τύποι εγγράφου, σχήματα, βέλη, πίνακες τιμών, όρια αντικειμένων και τοπική φόρτωση.
- `flowchart.ts`: μετατροπή του AST που επιστρέφει ο parser της ΓΛΩΣΣΑΣ σε επεξεργάσιμο διάγραμμα. Υποστηρίζει `ΔΙΑΒΑΣΕ`, `ΓΡΑΨΕ`, εκχώρηση, `ΑΝ`, `ΟΣΟ`, `ΓΙΑ` και `ΑΡΧΗ_ΕΠΑΝΑΛΗΨΗΣ`. Η κύρια ροή και τα σημεία ένωσης μένουν στον ίδιο κατακόρυφο άξονα. Η `ΓΙΑ` αναπτύσσεται σε αρχικοποίηση, συνθήκη και αύξηση μετρητή.
- `FlowShape.tsx`: επίσημα σχήματα διαγράμματος ροής, μαζί με πλάγιο παραλληλόγραμμο αποκλειστικά για είσοδο/έξοδο, και ορθογώνιες συνδέσεις με γωνίες 90°.
- `TraceTable.tsx`: πίνακας τιμών με βήματα από το 1, δυναμικές στήλες και υποχρεωτική τελευταία στήλη «ΕΞΟΔΟΣ». Οι παλιοί αποθηκευμένοι πίνακες ενημερώνονται κατά τη φόρτωση.
- `WhiteboardWorkspace.tsx`: εργαλειοθήκη, αρχικά κενά σχήματα, αλλαγή μεγέθους από τέσσερις γωνιακές λαβές, επεξεργασία κειμένου με διπλό κλικ, pan/zoom, αναίρεση/επανάληψη, εικόνες και εξαγωγή.

Το έγγραφο αποθηκεύεται τοπικά στον φυλλομετρητή και μπορεί να εξαχθεί ως JSON, SVG ή PNG. Οι εικόνες υποστηρίζονται σε PNG/JPEG/WebP έως 8 MB. Η αυτόματη δημιουργία διαγράμματος χρησιμοποιεί τον τελευταίο κώδικα από την καρτέλα του Διερμηνευτή και προσθέτει νέο, επεξεργάσιμο διάγραμμα στον πίνακα. Ο Πίνακας Τιμών συμπληρώνεται από τον μαθητή και δεν ισχυρίζεται ότι είναι αυτοματοποιημένη εκτέλεση του προγράμματος.

Έλεγχοι από τον φάκελο `aepp-generator-client`:

```text
npm run test:whiteboard
npm run build
```

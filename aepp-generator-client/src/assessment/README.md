# Διαδραστικά διαγωνίσματα

Το `model.ts` ορίζει διαγώνισμα 100 μονάδων, διακριτούς τύπους ερωτήσεων, φύλλο απαντήσεων και αναφορά. Το `practiceExam.ts` περιέχει πρωτότυπο διαγώνισμα εξάσκησης με 25 μονάδες σε κάθε θέμα. Οι απαντήσεις αποθηκεύονται προσωρινά στον browser μέχρι την υποβολή.

Το `grading.ts` διορθώνει αντικειμενικά ερωτήματα ανά πρόταση, αντιστοίχιση, κενό ή κελί. Για εκτελέσιμα προγράμματα δίνει 60% από τις δοκιμές και 40% από σταθμισμένα δομικά κριτήρια AST, με σάρωση υποπρογραμμάτων και έλεγχο της συνάφειας προς την έξοδο. Η εκτέλεση γίνεται σε Web Worker με όριο χρόνου ώστε να μην παγώνει η σελίδα. Η αναφορά δείχνει βαθμό /100 και /20, ενδεικτικές λύσεις, σύγκριση κώδικα και συγκεκριμένες ενότητες για επανάληψη.

Ο διερμηνευτής εκτελεί πλέον τις δοκιμές του Θέματος Δ με πίνακες 1Δ/2Δ και υποπρογράμματα. Το `generatedAdapter.ts` επιτρέπει διαδραστική επίλυση διαγωνισμάτων της γεννήτριας, αλλά το τρέχον JSON της γεννήτριας δεν περιέχει δομημένο κλειδί απαντήσεων ή δοκιμές· τα μόριά τους μένουν σε εκκρεμότητα.

Όταν λειτουργεί το backend και το `VITE_USE_DEMO=false`, η αναφορά ζητά συμπληρωματική ανάλυση από το Gemini μέσω `POST /api/exams/assessment-insight`. Οι προτάσεις πρόσθετων μορίων εμφανίζονται στον καθηγητή και δεν μεταβάλλουν μόνες τους τη βαθμολογία. Αν το Gemini δεν απαντήσει, η βασική αναφορά συνεχίζει να λειτουργεί.

Η αναφορά προγράμματος προσφέρει επιπλέον fuzzing οριακών τιμών στον Worker. Συγκρίνει τον κώδικα μαθητή με την πρότυπη λύση, ελέγχει αρνητικές/μηδενικές/μεγάλες τιμές, μορφές πινάκων και όρια αναζήτησης, και περιορίζει περιπτώσεις πίνακα όταν παραμένει η διαφορά. Το κουμπί «Άνοιγμα στον Debugger» μεταφέρει αυτούσιο τον κώδικα και τις τιμές εισόδου στον διερμηνευτή, όπου οι είσοδοι εμφανίζονται προγεμισμένες για βηματική εκτέλεση.

Το κουμπί «AI Code Review» στέλνει τον κώδικα και τα μετρικά εκτέλεσης (συγκρίσεις, εκχωρήσεις, επαναλήψεις) στο προστατευμένο `POST /api/code-review`. Το Gemini επιστρέφει χωριστή ανατροφοδότηση αποδοτικότητας, αλγοριθμικών κινδύνων και στυλ/κανόνων ΑΕΠΠ. Το endpoint απαιτεί σύνδεση, περιορίζεται με την πολιτική αιτημάτων AI και δεν εκτελεί ξανά τον κώδικα στον διακομιστή.

Οι δοκιμές κώδικα του παραδείγματος περιλαμβάνονται στο πακέτο του browser και είναι κρυφές μόνο από την οθόνη επίλυσης. Για εξετάσεις με ασφαλώς κρυφά δεδομένα απαιτείται εκτέλεση και βαθμολόγηση σε απομονωμένο διακομιστή.

Έλεγχοι:

```text
npm run test:assessment
npm run build
```

Τα schemas Zod εφαρμόζονται σε LocalStorage, αποκρίσεις API και Worker. Βλ. [αναλυτική τεκμηρίωση](../../../ASSESSMENT_GRADING.md).

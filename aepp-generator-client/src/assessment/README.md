# Διαδραστικά διαγωνίσματα

Το `model.ts` ορίζει διαγώνισμα 100 μονάδων, διακριτούς τύπους ερωτήσεων, φύλλο απαντήσεων και αναφορά. Το `practiceExam.ts` περιέχει πρωτότυπο διαγώνισμα εξάσκησης με 25 μονάδες σε κάθε θέμα. Οι απαντήσεις αποθηκεύονται προσωρινά στον browser μέχρι την υποβολή.

Το `grading.ts` διορθώνει αντικειμενικά ερωτήματα ανά πρόταση, αντιστοίχιση, κενό ή κελί. Για εκτελέσιμα προγράμματα δίνει μόρια από τέσσερις δοκιμές και περιορισμένα δομικά κριτήρια AST. Η εκτέλεση γίνεται σε Web Worker με όριο χρόνου ώστε να μην παγώνει η σελίδα. Η αναφορά δείχνει βαθμό /100 και /20, ενδεικτικές λύσεις, σύγκριση κώδικα και συγκεκριμένες ενότητες για επανάληψη.

Ο σημερινός διερμηνευτής δεν υποστηρίζει ακόμη πίνακες και υποπρογράμματα. Γι’ αυτό το Θέμα Δ μένει σε εκκρεμότητα, με δυνατότητα καταχώρισης βαθμού από καθηγητή. Το `generatedAdapter.ts` επιτρέπει διαδραστική επίλυση διαγωνισμάτων της γεννήτριας, αλλά το τρέχον JSON της γεννήτριας δεν περιέχει δομημένο κλειδί απαντήσεων ή δοκιμές· τα μόριά τους επίσης μένουν σε εκκρεμότητα.

Όταν λειτουργεί το backend και το `VITE_USE_DEMO=false`, η αναφορά ζητά συμπληρωματική ανάλυση από το Gemini μέσω `POST /api/exams/assessment-insight`. Οι προτάσεις πρόσθετων μορίων εμφανίζονται στον καθηγητή και δεν μεταβάλλουν μόνες τους τη βαθμολογία. Αν το Gemini δεν απαντήσει, η βασική αναφορά συνεχίζει να λειτουργεί.

Οι δοκιμές κώδικα του παραδείγματος περιλαμβάνονται στο πακέτο του browser και είναι κρυφές μόνο από την οθόνη επίλυσης. Για εξετάσεις με ασφαλώς κρυφά δεδομένα απαιτείται εκτέλεση και βαθμολόγηση σε απομονωμένο διακομιστή.

Έλεγχοι:

```text
npm run test:assessment
npm run build
```

# Ρυθμίσεις IDE

Το SettingsProvider περιβάλλει την εφαρμογή. Το useSettings παρέχει settings, update(patch), reset, persistent, unlockAudio, playSound και speak.

Οι προτιμήσεις γράφονται αμέσως στο aepp.settings.v1 ως {version:1,settings:{...}}. Οι τιμές ελέγχονται πριν εφαρμοστούν. Αλλαγές από άλλο tab συγχρονίζονται μέσω του storage event. Αν ο browser απαγορεύει την αποθήκευση, οι ρυθμίσεις συνεχίζουν να λειτουργούν στη συνεδρία με σχετική ένδειξη.

Το aepp.glossa.source.v1 περιέχει τον τελευταίο αυτόματα αποθηκευμένο κώδικα. Ο διερμηνευτής γράφει κάθε 5, 10 ή 30 δευτερόλεπτα και στο pagehide. Η επιλογή Απενεργοποιημένη σταματά αυτές τις εγγραφές. Το reset επαναφέρει μόνο τις προτιμήσεις, χωρίς διαγραφή κώδικα ή προόδου.

Η καθυστέρηση βήματος διαιρείται με την υπάρχουσα ταχύτητα 0.5× / 1× / 2×. Αλλαγές εφαρμόζονται στον επόμενο προγραμματισμό βήματος. Ο έλεγχος βρόχων διαβάζει το επιλεγμένο συνολικό όριο σε κάθε επανάληψη, ακόμη και σε εκτέλεση που έχει ήδη ξεκινήσει.

Ο editor χρησιμοποιεί κοινά μεγέθη γραμμής και πλάτη για textarea, syntax layer και gutter. Με αναδίπλωση, μετριούνται τα πραγματικά ύψη κάθε λογικής γραμμής ώστε η αρίθμηση και η ακολούθηση εκτέλεσης να παραμένουν σωστές.

Οι ήχοι χρησιμοποιούν Web Audio και είναι προαιρετικοί. Η φωνή χρησιμοποιεί Speech Synthesis με el-GR και τον επιλεγμένο ρυθμό. Δεν απαιτεί κλειδί API· η ελληνική φωνή εξαρτάται από τον browser/τη συσκευή. Στην κονσόλα, κάθε σφάλμα διαθέτει κουμπί Ανάγνωση σφάλματος.

Έλεγχοι: npm run test:settings, npm run build.

# Οπτικοποιητής Μνήμης & Πινάκων

Το MemoryVisualizer.tsx εμφανίζεται δίπλα στον editor (κάτω από αυτόν σε μικρή οθόνη). Το memory-visualizer.css περιέχει flash/focus animations και responsive styles. Τα στοιχεία μένουν στις πραγματικές θέσεις μνήμης τους: κινούνται οι τιμές, ενώ οι δείκτες παραμένουν σταθεροί από το 1. Η ένδειξη — σημαίνει ότι δεν υπάρχει αρχική τιμή, ποτέ αυτόματη τιμή 0.

## Σύνδεση

Ο InterpreterWorkspace δημιουργεί new Interpreter(program, { memory: true }).execute(). Κάθε ήδη υπάρχον step/input/done event περιέχει memoryEvents, scopeId, scopeName και variables. Το component λαμβάνει event, speed και onSpeedChange. Η καταγραφή είναι προαιρετική: οι worker έλεγχοι αξιολόγησης χρησιμοποιούν τον interpreter χωρίς αυτήν.

Οι πίνακες στα VariableSnapshot περιέχουν dimensions και elements. Τα κλειδιά στοιχείων είναι οι δείκτες χωρισμένοι με κόμμα (π.χ. 1 ή 2,3) και η τιμή τους είναι Value. Τα μη αρχικοποιημένα στοιχεία απουσιάζουν από το sparse record. Κάθε snapshot αντιγράφει τις τιμές του και δεν μεταβάλλεται από επόμενη εκτέλεση.

## Events

- ON_READ: target = { scopeId, name, indexes }, value και προαιρετικό input. Εκπέμπεται κατά πραγματική ανάγνωση μεταβλητής/στοιχείου και κατά αναμονή ΔΙΑΒΑΣΕ.
- ON_COMPARE: operands, operator, leftValue, rightValue, result. Εκπέμπεται από τις συγκρίσεις του AST μετά από έλεγχο τύπων. Οι δείκτες δεν επαναξιολογούνται για το animation.
- ON_MUTATE: target, previous, value, προαιρετικό source. Εκπέμπεται μόνο μετά από επιτυχή εγγραφή. Το source υπάρχει σε άμεση αντιγραφή μεταβλητής/στοιχείου και κινεί την τιμή προς τον προορισμό.
- ON_SWAP: first, second, temporary, values. Το SwapTracker αναγνωρίζει τρεις διαδοχικές εκτελεσμένες άμεσες εκχωρήσεις της μορφής Τ <- Α[Ι], Α[Ι] <- Α[Κ], Α[Κ] <- Τ, με τις ίδιες πραγματικές θέσεις, ανεξάρτητα από τα ονόματα. Παρεμβολή άλλης εντολής ή αλλαγή δεικτών ακυρώνει την αναγνώριση. Το τελικό animation αναπαριστά την ολοκληρωμένη αντιμετάθεση, αφού τα προηγούμενα βήματα έχουν δείξει τις μεταφορές μέσω Τ. Δεν γίνεται αλλαγή της σημασιολογίας του προγράμματος.

Κάθε κλήση υποπρογράμματος έχει δικό της scopeId. Το panel δείχνει το ενεργό πλαίσιο, με τοπικές μεταβλητές και παραμέτρους. Η επιστροφή επαναφέρει την προβολή στον καλούντα.

## Ταχύτητα και δείκτες

Ο slider επιλέγει 0.5×, 1× ή 2×. Ένα αυτόματο βήμα προγραμματίζεται ανά 1050/speed ms και ένα animation διαρκεί 900/speed ms. Η Παύση σταματά το επόμενο βήμα, η Επαναφορά καθαρίζει μνήμη και timers, και η αλλαγή πηγαίου κώδικα ακυρώνει την τρέχουσα εκτέλεση. Το ΔΙΑΒΑΣΕ περιμένει υποβολή και συνεχίζει στον προηγούμενο τρόπο εκτέλεσης. Η έκδοση αυτή δίνει προτεραιότητα στην παρακολούθηση βημάτων στην αυτόματη εκτέλεση.

Η αντιστοίχιση αναζήτησης αναγνωρίζει ΑΡΧ/ΑΡΧΙΚΗ/ΑΡΧΗ_ΑΝΑΖΗΤΗΣΗΣ/START/LEFT/LOW, ΤΕΛΟΣ/END/RIGHT/HIGH και ΜΕΣΟ/ΜΕΣΟΣ/MID/MIDDLE (χωρίς διάκριση τόνων/πεζών). Από «Δείκτες δυαδικής αναζήτησης» επιλέγονται συγκεκριμένος πίνακας και ακέραιες μεταβλητές, ή απενεργοποιούνται οι δείκτες. Η λέξη ΑΡΧΗ είναι δεσμευμένη στη ΓΛΩΣΣΑ και δεν χρησιμοποιείται ως όνομα μεταβλητής. Δείκτης εκτός ορίων δηλώνεται στην ένδειξη τιμών· δεν προβάλλεται πάνω σε λάθος κελί.

Μεγάλοι πίνακες προβάλλονται σε τμήματα 24 στοιχείων για 1Δ ή 6×8 για 2Δ. Υπάρχει επιλογή τμήματος και αυτόματη εστίαση σε πρόσφατη προσπέλαση. Για αντιμετάθεση μεταξύ μη ταυτόχρονα ορατών τμημάτων παραμένουν η σωστή ενημέρωση και η περιγραφή· η κίνηση εκτελείται όταν και οι δύο θέσεις είναι ορατές. Το prefers-reduced-motion απενεργοποιεί τις κινήσεις και κρατά τιμές, ετικέτες και χρώματα.

## Έλεγχοι

npm run build

npm run test:memory

Οι δοκιμές καλύπτουν σύγκριση, ενδιάμεσες τιμές swap, ανεξάρτητα snapshots, είσοδο 2Δ, δυαδική αναζήτηση, όρια, διακοπτόμενες τριάδες, πλαίσια υποπρογραμμάτων και αμετάβλητη έξοδο με ενεργό instrumentation. Γίνεται επιπλέον server render του component για τις ετικέτες θέσεων και τη σελιδοποίηση. Η εκτέλεση ελέγχεται στον ενσωματωμένο interpreter της εφαρμογής.
